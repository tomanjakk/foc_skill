# 外部工程的 PWM 定时器与 ADC 配置

外部工程接入这套 FOC 时，应提供以下配置和行为。具体定时器、ADC、引脚和时钟由目标 MCU 与原理图决定；不能满足要求或实际时序尚未确认时，应说明差异，不能直接认定兼容。

## PWM 模式

1. **三相 PWM**：U、V、W 三路配置为中心对齐 **PWM 模式 1**。参考工程中，比较参考信号在 `CNT < CCRx` 时有效、`CNT > CCRx` 时无效；主输出配置为高电平有效，因此稳定区间分别对应高、低电平。每相提供主输出和互补输出，并配置比较值预装载。互补输出还受互补极性、死区及输出使能影响，须按实际功率级和原理图核对。
2. **ADC 触发通道 CH4**：配置为 **PWM 模式 2**。参考工程的比较参考信号在 `CNT < CCR4` 时无效、`CNT > CCR4` 时有效；以高电平有效理解，稳定区间分别为低、高电平。CH4 使用独立比较值确定采样触发时刻，不作为三相功率输出。

参考工程的三路 ADC 注入组选择 `TIM1_CC4` 比较事件为触发源，并配置为响应内部触发信号的**上升沿**。定时器 `CNT` 与 `CCR4` 比较匹配时产生相应的 CH4 比较事件，以此触发采样；这不是计数到顶点或底点的更新事件。虽然 TIM1 同时配置了 `TRGO = OC4REF`，当前 ADC 选择的是 `TIM1_CC4`，不能直接把它写成 ADC 由 `OC4REF` 的引脚电平上升沿触发。

中心对齐下上数和下数都会经过比较值；比较事件在哪个方向有效、ADC 实际收到几次触发，以及 `CNT == CCR` 时输出如何切换，必须根据目标 MCU 的定时器/ADC 手册及计数方向判断，并通过波形或计数验证。不能仅凭 `CNT > CCR4` 是高电平，就认定所有高电平期间都会采样。

如果目标 MCU 的通道编号或 PWM 模式命名不同，必须依据芯片手册确认实际输出与触发行为等效；不能仅按名称判断。未经适配，不能将三相改为 PWM 模式 2 后直接沿用现有占空比与极性。

## 外部工程必须提供的行为

| 项目 | 对接要求 |
|---|---|
| 载波和控制周期 | PWM 载波频率由目标项目定义。电流环与 PWM 同步；`PWM_TIM_FREQ`、`CURRENT_LOOP_FREQ`、`Current_Ts` 与实际执行频率一致。速度环、位置环频率及分频按项目定义，并检查算法周期与实际调度一致。 |
| 占空比更新 | 提供 U/V/W 比较值写入接口，按现有 FOC 占空比语义映射到三相；使用预装载并在预期更新事件生效，避免三相更新跨周期。 |
| 硬件死区与保护 | 为互补输出配置符合实际驱动器和功率管要求的硬件死区，并检查故障关断、输出极性和空闲状态；软件死区补偿不替代硬件死区。 |
| 软件死区补偿 | 初始配置的软件死区补偿时间不得低于 **400 ns**；明确该值的单位及是否包含驱动器、定时器等延时，避免重复计算。后续调整须结合目标功率级参数和实测波形评估；该限制不代表硬件死区已满足要求。 |
| 三相电流采样 | 优先使用不同的 ADC 分别采集 U/V/W，各 ADC 使用自己的注入组，并由 CH4 的同一个定时事件触发；三路结果按相序传递且属于同一触发周期。目标 MCU 不支持该方案时，可评估使用同一个 ADC 注入组的不同通道依次采样：按实际序列映射 U/V/W，保证一组结果完整、无新旧周期混合，并评估通道间采样时间差、全部转换耗时及其对 FOC 的影响；无法满足时停止并报告，不宣称等同于三 ADC 同步采样。 |
| ADC 采样保持时间 | 每个相电流通道的 ADC **采样保持时间不得小于 12.5 个 ADC 时钟周期**；若目标 ADC 不支持恰好 12.5 周期，选择满足该下限的可用档位。还要根据 ADC 实际时钟、输入阻抗和模拟前端建立时间核对，不得认为 12.5 周期必然足够。此要求不等于两次触发间隔，也不等于采样加转换的总时间。 |
| 采样时刻 | 根据载波周期、计数方向、功率级开关状态、放大器建立时间及 ADC 采样保持时间，配置 CH4 比较值和触发边沿；确认整个采样窗口有效，不能直接照搬其他项目的 CCR 值。 |
| 采样完成与 FOC | 三相采样全部完成后提交 `FOC_Port_SetFastInput()`，再按当前 FOC 调用链执行一次 `FOC_Run()`；检查重复完成、丢样及执行截止时间，避免新旧数据混合。 |
| 启动和停止 | 先使采样通道进入等待触发状态，再启动 PWM 定时器和 ADC 触发；初始化时保持三相功率输出关闭。提供功率输出使能、关闭和故障停机接口，并核实采样时基与功率输出的独立控制方式。 |
| 慢速采样 | 使用独立的普通定时器产生 **1 kHz 中断**，在其中调度母线电压、电机温度及 MOS 温度采样；ADC 配置为**规则组采样**。按目标板确定通道、换算和滤波；若与电流注入采样共用 ADC，核对规则组与注入组的转换仲裁、数据完整性及对电流采样时序的影响。 |
| 电流换算 | 根据实际 ADC 满量程、参考电压、采样电阻、放大倍数和零偏，将各相采样转换为 FOC 所需电流单位与方向；确认三相映射和极性。 |

外部工程应提供定时器/ADC 初始化、采样启动、三相比较值写入、PWM 使能/关闭及故障停机、三相和慢速采样数据传递等接口，并对接现有 FOC 端口；函数名按目标工程实际接口确定。

## 采样时间和触发位置的确定

- **先算采样保持时间**：`采样保持时间 = 采样周期数 / ADC 实际时钟频率`。例如 ADC 时钟为 42.5 MHz 时，12.5 周期约为 0.294 μs，47.5 周期约为 1.118 μs；这是采样保持时间，不含触发延迟和后续转换时间。12.5 周期是本方案下限，不代表模拟前端一定能在此时间内稳定：还要核对 ADC 手册的输入要求，以及电流放大器、输出阻抗、滤波电阻和电容的建立时间。缩短前后比较零偏、噪声及不同占空比下的电流采样结果，必要时增加采样时间。
- **检查整个窗口**：从实际开始采样到采样保持结束都应处于有效电流通路和模拟前端稳定区；不能只确认 CH4 比较事件位于稳定区。转换完成还需额外时间，并要在控制计算截止时间前完成。高、低占空比和不同扇区的窗口可能不同，应分别验证。
- **重新确定 CCR**：触发比较值取决于定时器时钟、计数周期与方向、功率级和模拟前端的时序；已有工程中固定的 `CCR4 = 3707` 仅为具体工程的配置示例，不能直接复用，也未证明其在所有占空比下有效。修改 PWM 频率、ADC 时钟、采样保持时间或功率级后，应重新核算并实测采样窗口。
- **注意共享通道配置**：有些 MCU 的采样时间按 ADC 通道设置，规则组和注入组若共用该通道，后续初始化或动态配置可能覆盖采样时间。核对目标芯片手册和初始化顺序，检查规则组与注入组的转换仲裁以及电流采样时序。

## 母线电压和温度的规则组采样

使用普通定时器提供 1 kHz 中断，在中断中按目标 ADC 的规则组接口调度母线电压、电机温度、MOS 温度的采样。三个量分别映射到实际硬件通道；按目标 MCU 能力选择逐通道采样或规则组序列，不能假定转换结果在启动瞬间已经有效。

中断中应保持执行时间可控：根据 ADC 转换方式读取已完成的数据或启动转换并在完成后取值，不在中断中无界等待。明确结果的完成状态、通道顺序和更新周期；如果一次中断不能完成全部通道，说明各通道实际刷新率。电压与温度的比例、单位、滤波和有效范围按分压、温度传感器及目标工程配置确定。

若规则组和三相电流注入组共用 ADC，依据目标 MCU 手册确认并测量转换优先级、打断／恢复行为和最坏耗时，保证三相电流采样与控制周期满足要求；普通定时器 1 kHz 中断不代替 CH4 对电流注入采样的触发。验证时分别检查普通定时器中断频率、三个通道数据更新及换算，并核对慢速采样开启前后电流采样时序和错误计数。

## 对接验证

配置完成后必须进行对接验证，先静态核对，再在用户授权的范围内按下列顺序验证；某项无法执行时标记未验证，不能宣称对接已完成。连接、采集、下载、复位和电机运行分别按用户授权执行。

1. **三相 PWM 和 SVPWM**：依据原理图选择正确的安全测量方法，检查 U/V/W 与软件占空比的对应关系、实际载波周期、中心对齐、主/互补极性及硬件死区。用适当的电压矢量变化检查三相占空比连续变化和电角度相序；SVPWM 共模注入后，单相占空比包络不必是纯正弦。比较命令、定时器输出和实际功率级信号，不只看软件变量。
2. **ADC 采样窗口**：同时观察有关相位的 PWM/栅极信号、相应电流放大器输出以及可用的 ADC 触发时序标记；确认实际触发次数、采样保持窗口及转换完成时刻。整个采样保持窗口应处于目标拓扑下的有效电流通路和模拟前端稳定区，避开开关瞬态、死区及放大器振铃；在预计的占空比范围内检查，而非只看单个工况。对顺序采样还要检查三相采样时间差。
3. **三相数据对应**：核对 PWM 相序、实际电机相线、采样电路、ADC 通道及 FOC 的 `Ia/Ib/Ic` 映射和正负方向；检查零偏、增益、量程及三相数据完整性。`Ia + Ib + Ic` 接近零只能作辅助检查，不能单独证明相序或极性正确。
4. **采样到 PWM 生效**：核对 ADC 触发 → 采样完成 → 三路汇合 → `FOC_Run()` → CCR 预装载写入 → 更新事件实际生效的顺序、频率、最坏耗时和抖动；确认三个 CCR 不会跨装载事件，FOC 按预期次数执行，并检查同步错误计数。完成标志或同步错误计数为零不能证明模拟采样同步和窗口有效。
5. **角度和电流环**：确认编码器方向、极对数、电角度零位以及角度数据与 ADC 采样之间的时间差；核对算法假设的采样到 PWM 生效延迟。先完成上述检查，再依据实际环路数据调整电流 PI 和限幅。V/F 能转不等于电流相序、采样时序或电角度已经正确。

采样触发标记和 ADC 中断入口标记含义不同：中断标记还包含转换及中断响应延迟，不能直接当成采样起点。若现有工程没有可观测信号，先说明缺口；需要增加调试引脚或代码时，应先说明拟修改内容，不擅自修改。示波器波形、实测周期及项目允许误差用于验收；源码配置和静态计算不能替代板级证据。

### 三路同步与执行频率排查

1. 在授权的采集范围内，分两次记录完整采样组计数及时间，计算增量除以间隔，得到平均采样组频率；用同样方法记录 FOC 执行次数，与目标频率及各自计数比较。计数读取不是同时发生时，要考虑采集时间误差；平均频率不能证明单周期无抖动或无丢样。
2. 检查同步错误计数是否增长。如果增长，核对各 ADC 触发源和边沿、通道与中断使能、完成标志处理，以及一组数据完成前是否又出现同一路完成。检查计数器回绕、复位及读取范围，不能将不同时间或固件版本的数值直接比较。
3. 若采样组数与 FOC 执行次数不一致，检查调度标志是否被覆盖、执行是否超时，以及预装载更新时刻。用可观测的时序标记或其他合适手段测量最坏耗时和抖动，确认完成计算并提交三相 CCR 时，仍能赶上预期的装载事件。

参考工程可观察 `adc_complete_sample_sequence` 和 `adc_sync_error_count`；名称及计数含义应以实际代码为准。同步错误计数为零不证明三路模拟采样同时发生，也不证明采样窗口有效；没有 FOC 执行计数或时序标记时应标记为未验证。
