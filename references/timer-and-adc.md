# 外部工程的 PWM 定时器与 ADC 配置

外部工程接入这套 FOC 时，应提供以下配置和行为。具体定时器、ADC、引脚和时钟由目标 MCU 与原理图决定；不能满足要求或实际时序尚未确认时，应说明差异，不能直接认定兼容。

## PWM 模式

1. **三相 PWM**：U、V、W 三路配置为中心对齐 **PWM 模式 1**，每相提供主输出和互补输出，并配置比较值预装载。三相映射、输出极性和空闲状态按目标功率级及原理图核对。
2. **ADC 触发通道 CH4**：配置为 **PWM 模式 2**，用独立比较值确定采样触发时刻，不作为三相功率输出。外部工程应核对目标 MCU 的比较事件、触发源与边沿，实现与本 FOC 采样链路一致的行为。

如果目标 MCU 的通道编号或 PWM 模式命名不同，必须依据芯片手册确认实际输出与触发行为等效；不能仅按名称判断。未经适配，不能将三相改为 PWM 模式 2 后直接沿用现有占空比与极性。

## 外部工程必须提供的行为

| 项目 | 对接要求 |
|---|---|
| 载波和控制周期 | PWM 载波频率由目标项目定义。电流环与 PWM 同步；`PWM_TIM_FREQ`、`CURRENT_LOOP_FREQ`、`Current_Ts` 与实际执行频率一致。速度环、位置环频率及分频按项目定义，并检查算法周期与实际调度一致。 |
| 占空比更新 | 提供 U/V/W 比较值写入接口，按现有 FOC 占空比语义映射到三相；使用预装载并在预期更新事件生效，避免三相更新跨周期。 |
| 硬件死区与保护 | 为互补输出配置符合实际驱动器和功率管要求的硬件死区，并检查故障关断、输出极性和空闲状态；软件死区补偿不替代硬件死区。 |
| 软件死区补偿 | 初始配置的软件死区补偿时间不得低于 **400 ns**；明确该值的单位及是否包含驱动器、定时器等延时，避免重复计算。后续调整须结合目标功率级参数和实测波形评估；该限制不代表硬件死区已满足要求。 |
| 三相电流采样 | U/V/W 相电流由 PWM 定时事件同步触发，按相序传递原始采样值；保证三相数据对应同一采样周期。ADC 分辨率、参考电压、采样时间和触发边沿按目标芯片及模拟前端确定。 |
| 采样时刻 | 根据载波周期、计数方向、功率级开关状态、放大器建立时间及 ADC 采样保持时间，配置 CH4 比较值和触发边沿；确认整个采样窗口有效，不能直接照搬其他项目的 CCR 值。 |
| 采样完成与 FOC | 三相采样全部完成后提交 `FOC_Port_SetFastInput()`，再按当前 FOC 调用链执行一次 `FOC_Run()`；检查重复完成、丢样及执行截止时间，避免新旧数据混合。 |
| 启动和停止 | 先使采样通道进入等待触发状态，再启动 PWM 定时器和 ADC 触发；初始化时保持三相功率输出关闭。提供功率输出使能、关闭和故障停机接口，并核实采样时基与功率输出的独立控制方式。 |
| 慢速采样 | 提供母线电压、MOS 温度和电机温度所需采样；其周期、通道、换算和滤波按目标项目确定。若与电流采样共用 ADC，核对转换仲裁和对控制周期的影响。 |
| 电流换算 | 根据实际 ADC 满量程、参考电压、采样电阻、放大倍数和零偏，将各相采样转换为 FOC 所需电流单位与方向；确认三相映射和极性。 |

外部工程应提供定时器/ADC 初始化、采样启动、三相比较值写入、PWM 使能/关闭及故障停机、三相和慢速采样数据传递等接口，并对接现有 FOC 端口；函数名按目标工程实际接口确定。

## 对接验证

先依据目标 MCU 手册和原理图检查配置与调用链；再根据用户授权，分别验证三相主/互补波形、硬件死区、CH4 触发及实际 ADC 采样位置、三相数据对应、FOC 周期和比较值生效时刻。频率、采样窗口和安全关断未实测时应标明未验证；不将源码配置当成波形证据。连接、采集、下载、复位和电机运行分别按用户授权执行。
