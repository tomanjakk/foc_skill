# FOC 历史调试经验

来源是原工程的 `.mklink` 历史记录；记录只对应当时的固件、板卡、电机和工况。使用时先核对目标源码、硬件、单位和记录来源。历史数值不作为新目标的默认参数或验收标准。连接、采集、写目标、烧录和电机运行须有用户对相应操作的明确授权。

## 固件、符号和数据

- 记录工程、Target、构建日志、下载镜像和 AXF 的路径及摘要；确认目标实际运行的固件与符号对应，文件路径相同不能证明固件一致。
- 输出目录被占用或产物版本不确定时，先定位问题；可按目标工程建立隔离构建并核对其产物，不能用旧 AXF 解释新固件。隔离构建仍属于编译，按用户授权执行。
- 区分 MCU 内部采样或计算频率、上位机轮询周期、采集请求间隔和实际采样率；未测量时不宣称达到请求的采样率。检查采样数据完整性、时间戳和丢帧计数。

## 参数辨识

- 电阻辨识除结果外，检查拟合点、残差、滞回、独立验证点和重复性；明确相电阻与线电阻的定义和换算条件。
- 电感辨识记录有效样本数、转子位置和速度、测试条件及重复结果；依照目标电机和方法区分 Ld、Lq，不能因历史记录相同而假设目标相同。
- 检查状态、错误原因和测试结束状态。数据合理性不等于已完成外部仪器交叉验证。

## 电流环与采样

- 扫频或阶跃分析同时记录激励、母线、电流、采样与控制周期、原始反馈和滤波反馈、幅值、相位、峰值及饱和状态。比较方案时保持测试条件一致。
- 首次下降穿越 -3 dB 的闭环幅值带宽是一种测量定义；记录归一化基准、插值和相位处理方式。闭环跟随相位不是开环相位裕度，不凭带宽单独判断稳定性。
- 采样率接近测试频率时关注每周期采样点数及测量方法的限制；外部电流波形、带载高速、温升等未测项目应明确列出。
- 区分滤波前后量，评估滤波延迟、噪声与共振；没有对照数据时不将滤波后曲线改善等同于实际电流改善。

## 轨迹与位置

- 根据目标机构允许行程和安全条件设计小行程、正反向、返回和运动中改变目标的测试；观察位置指令、轨迹、反馈、速度、电流、跟踪误差及故障状态。
- 检查电机侧与负载侧、方向、角度单位及减速比；记录采集丢帧、结束状态和未覆盖工况。不得照搬历史轨迹范围或限值。
